อัปรูป + สร้างลิงก์ NFC

เลือกรูป → กดอัปโหลด → ได้ลิงก์เขียน NFC เลย รูปตั้งชื่อสุ่มอัตโนมัติ คนอื่นเดาไม่ได้

ตั้งค่า GitHub (ครั้งแรกครั้งเดียว) สร้าง Token ที่ github.com/settings/tokens → Fine-grained → เลือกเฉพาะ repo nfc → สิทธิ์ Contents: Read and write → คัดลอกมาวาง (เครื่องจำให้ ไม่ส่งไปไหน)
