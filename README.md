# กรอบรูป NFC

ระบบโชว์รูปเมื่อแตะ NFC — ไฟล์เดียวใช้ได้กับทุกคน แต่ละกรอบมีรหัสสุ่มเฉพาะตัว

## โครงสร้าง
- `index.html` — หน้าโชว์รูป (อ่านชื่อรูปจากลิงก์, หลายรูปปัดซ้ายขวาได้)
- `make.html` — ตัวช่วยสร้างกรอบใหม่ + ลิงก์ NFC
- `img/` — เก็บไฟล์รูปของทุกคน
- `.nojekyll` — ให้ GitHub Pages เสิร์ฟไฟล์ตรง ๆ

## วิธีเพิ่มกรอบใหม่ (แต่ละคน)
1. เปิด `make.html` → ใส่ Base URL + จำนวนรูป → กด "สร้างกรอบใหม่"
2. ตั้งชื่อไฟล์รูปตามรหัสที่ได้ แล้ววางในโฟลเดอร์ `img/`
3. อัปขึ้น GitHub (ผ่าน GitHub Desktop กด Push)
4. ก๊อปลิงก์ไปเขียนลงแท็ก NFC ด้วยแอป NFC Tools

## แก้/ลบรูป
- เปลี่ยนรูป: วางไฟล์ชื่อเดิมทับใน `img/` → Push
- ลบกรอบ: ลบไฟล์รูปออกจาก `img/` → Push
